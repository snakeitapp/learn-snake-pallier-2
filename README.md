🐍 Make Your Own Snake – Pallier 2

Prototype of a mobile learning app where users learn programming by progressively building their own Snake game.

This project is an early technical prototype exploring the concept of combining interactive coding lessons with a live playable game preview.

The goal is to create a learning experience similar to apps like Mimo or Duolingo, but focused on building a game step-by-step.

🎮 Current Features (Pallier 2)
